This puzzle has 3 things: a background, many. long rectangular frames, and patterns within each frame (of repeating units)

Within each instance of the puzzle, vary the following:
- more diversity in the number of frames in a puzzle
- more diversity in the heights of the rectangular frames

Between puzzle instances
- some puzzles can have the train pairs be vertical with their test pairs being horizontal (currently all of the are reverse)
- some puzzles can have both train and test pairs have the same orientation

In general, don't keep constant orientations. Vary them like crazy across train pairs, test pairs, test/train, instances, etc. 

Keep 1/14th of the puzzles instances with minimal orientation variation (like all same orientation or all train have 1 orientation and all testhave another). Point being if all max variations occur all the time, then also the model gets confused when there is no variation
